# Овнезей

Горизонтальная пиксельная текстовая новелла для Android. Рассказчик, диалоги, персонажи появляются слева или справа, выбор кнопками. Сюжет и мир описаны в документе «Овнезей — библия мира».

## Структура

| Путь | Назначение |
|---|---|
| `engine/` | Чистый Kotlin без Android: формат сценария `.ovn`, парсер, исполнитель сюжета, сохранения. Покрыт тестами |
| `app/` | Android-приложение: один экран, загрузка сценария из `assets/story/`, портреты из `assets/portraits/`, сохранение прогресса |
| `app/src/main/assets/story/demo.ovn` | Заглушка для проверки движка, заменяется сценами сюжета |

Зависимостей, кроме Kotlin, нет. Android-модуль использует только платформенные классы.

## Сборка и тесты

Нужны Android Studio (или JDK 17+ и Android SDK 35).

```
./gradlew :engine:test        # тесты движка
./gradlew :app:assembleDebug  # отладочная сборка
```

Версии: Gradle 8.9, AGP 8.7.3, Kotlin 2.0.21, compileSdk/targetSdk 35, minSdk 27 (Android 8.1).

## Формат сценария `.ovn`

```
# комментарий
@scene start               # начало сцены; сцена start обязательна
> Текст рассказчика
Чарли@left: Реплика        # @left или @right задают сторону, дальше она запоминается за именем
Сэм: Ещё реплика           # без стороны: берётся последняя, по умолчанию left
@set has_letter            # установить флаг
@if has_letter -> scene_b  # переход, если флаг есть; @if !flag -> ... если флага нет
@goto scene_b              # безусловный переход
@choice                    # выбор, варианты идут сразу под ним
* Взять письмо -> take
* Пройти мимо -> skip ? !has_letter   # условие показа: ? флаг или ? !флаг
@end                       # конец сюжета
```

Правила: имена сцен и флагов только латиница, цифры и `_`. Каждая сцена заканчивается `@end`, `@goto` или `@choice`. Перенос строки внутри текста `\n`. Ошибки показываются с номером строки.

## Сохранения

Состояние (сцена, позиция, флаги) хранится строкой `v1|сцена|позиция|флаги`. Повреждённое сохранение или сохранение от другой версии сюжета игнорируется, и сюжет начинается заново.
